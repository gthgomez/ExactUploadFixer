
BABEL · governance-first control plane
CLI · abstract layered architecture

Usage: babel [options] [command]

Babel Multi-Agent OS — governance-first runtime harness for multi-repo
workspaces

Options:
  -V, --version                         output the version number
  -h, --help                            display help for command

Commands:
  dry [options] [state]                 Everyday safety toggle: inspect or
                                        persist Babel dry-run executor mode
  doctor [options]                      Everyday diagnostic: run Babel
                                        workspace health and integrity checks
  mcp                                   Advanced/internal: run the read-only
                                        Babel MCP control-plane server over
                                        stdio
  inspect                               Read-only run inspection surfaces for
                                        existing Babel evidence bundles
  run [options] <task>                  Everyday command: run a task through
                                        the full Babel pipeline
  plan [options] <project> <intent...>  Manual Bridge start flow (non-breaking
                                        alias for: run --mode manual --project
                                        <project> <intent...>)
  resume [options]                      Manual Bridge resume flow from a
                                        validated plan.json file
  apply [options]                       Legacy alias for resume (Manual Bridge
                                        resume flow)
  smoke [options]                       Advanced diagnostic: run Manual Bridge
                                        smoke suite and summarize executor
                                        outcomes
  test [options] [project]              Legacy alias for smoke diagnostic; not
                                        a general project test runner
  help [command]                        display help for command


▌ WORKFLOWS · common entry points ───────────────────────────────────────────────────
  Examples:
  $ babel run "Fix webhook retry handling" --project GPCGuard
  $ babel dry status
  $ babel dry off
  $ babel doctor --scope repos --json
  $ babel inspect run latest
  $ babel plan Prismatix "Prepare rollout plan"
  $ babel resume --project GPCGuard --plan clipboard
  $ babel GPCGuard "Investigate dashboard latency"

▌ COMMAND GUIDE · operator surfaces ─────────────────────────────────────────────────
  Command Guide:
  Everyday:          run, doctor, dry
  Inspection:        inspect
  Manual Bridge:     plan, resume, apply (legacy alias)
  Diagnostics:       smoke, test (legacy alias)
  Advanced/Internal: mcp

▌ NOTES · layered workflow ──────────────────────────────────────────────────────────
  Notes:
  - Shorthand is supported: babel <Project> "<task...>" maps to babel run --project <Project> "<task...>".
  - Dry mode defaults to ON unless explicitly disabled. Use "babel dry status|on|off" for the friendly toggle surface.
  - Use "babel <command> --help" for command-specific examples and caveats.
